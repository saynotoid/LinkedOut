### 🎯 Про проєкт
Професійна соціальна мережа для розробників. 
Клон LinkedIn для відпрацювання архітектурних рішень на .NET 10.

### 🛠 Технологічний стек
*   Бекенд: .NET 10 (Minimal APIs)
*   База даних: PostgreSQL (Supabase)
*   Аналіз коду: SonarCloud
*   CI/CD: GitHub Actions
